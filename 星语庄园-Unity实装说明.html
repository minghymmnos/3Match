星语庄园 · Unity 实装交付说明

Unity 2022.3.39f1 ｜ 工程：E:\unityhub\project\3Match ｜ 依据《星语庄园-游戏策划案》与《美术及UI需求文档》

如何运行

  • 用 Unity Hub 打开工程 E:\unityhub\project\3Match（首次打开会自动导入资源并编译脚本）。
  • 打开场景 Assets/Scenes/MainMenu.unity，点击 Play 即可从主界面开始游戏。
  • 构建已包含 MainMenu 与 Gameplay 两个场景（Build Settings 已配置，竖屏）。
  • 测试辅助：设置面板内提供「+5000 金币」「无限生命 2 小时」；生命不足面板提供「+1 生命」。

资源目录结构

  • Assets/Art/Resources/Pieces — 6 色基础棋子 + 4 种特殊棋子（从美术素材目录复制）
  • Assets/Art/Resources/Backgrounds — 庄园主界面 / 关卡地图 / 花园关卡背景
  • Assets/Art/Resources/UI — 按钮三态 / 货币图标 / 关卡节点 / 进度条 / 弹窗底 / 棋盘底
  • Assets/Art/Resources/Effects — 6 色消除爆发 / 爆炸闪光 / 彩虹波 / 星光拖尾
  • Assets/Resources/Levels/levels.json — 关卡配置（10 关）
  • Assets/Scripts/Core — 棋盘模型 / 存档 / 音效 / 流程；Assets/Scripts/UI — UI 与特效

技术要点

  • 棋盘逻辑为纯 C# 数据层（BoardModel），表现层只做动画，便于后续接入关卡编辑器与模拟器。
  • 全部 UI 由代码构建（UGUI + 系统动态中文字体），场景仅含 Camera + Bootstrap 自举组件，无序列化引用断裂风险。
  • 图集切片坐标集中在 SpriteLib（按钮三态纵向 3 帧、货币图标横向、关卡节点横向 5 帧、消除爆发 3×2）。

当前范围与后续建议

  • 本版本为可玩性完整的核心 Demo：10 个配置关卡 + 4 种特殊棋子 + 6 类组合 + 2 种障碍。庄园建设/社交/活动/商城为占位入口，属后续里程碑（对应策划案 §8.3 P2–P5）。
  • 障碍物（木箱/冰层）暂用程序绘制占位块，待美术「待补清单」资源到位后在 BoardController.CreateObstacleView 替换贴图即可。
  • 其余 5 色棋子的选中/高亮状态按素材清单建议由程序派生（当前用缩放选中态实现）。
